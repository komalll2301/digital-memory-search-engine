How it works
1. Select files→2. Extract text (parsers / OCR)→3. Split into chunks→4. BM25 index→5. Rank + threshold→6. Answer with source evidence
  • Credentials (passwords, OTP, PIN, tokens) are never indexed and such queries are refused.
  • If no chunk matches enough of the query, the system says so instead of guessing (no-evidence response).
  • Only files you explicitly select are indexed; "Revoke" deletes the index from memory.
